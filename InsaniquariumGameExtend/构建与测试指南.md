# 构建与测试指南：InsaniquariumGameExtend（Feature 架构）

本项目已重构为 **Core 基础设施 + Features 功能模块** 的分层架构（参照 CulturesGameExtend）。
每个功能以 `Feature` 子类封装，通过 `REGISTER_FEATURE` 宏自注册，由 `FeatureManager` 统一调度。
所有游戏函数地址与类型集中在 `GameApi.h` 统一管理。

当前功能：
- **[SigCheck]** — 禁用 .sig 签名校验（让被修改的资源文件能正常加载）
- **[StoreAllFish]** — 商店扩展：把被隐藏的鱼/道具强制显示到第二行（含 6 种鱼 + 星药剂 + 捕星者），保留科技树

---

## 一、项目结构

```
InsaniquariumGameExtend/
├── dllmain.cpp                    # 入口：LogInit → EnsureDefaultIni → cfg.Load → ver.Detect → FeatureManager::InstallAll
├── pch.h / pch.cpp                # 预编译头（标准库 + Core/fs_compat.h）
├── framework.h                    # WIN32_LEAN_AND_MEAN + <windows.h>
├── InsaniquariumGameExtend.ini    # 配置文件（Feature-based 分段格式）
├── Core/                          # ---- 基础设施层 ----
│   ├── Logger.h / .cpp            # 线程安全日志（LOG_INFO/DEBUG/WARN/ERROR）
│   ├── IniConfig.h / .cpp         # 零依赖 INI 解析器
│   ├── GameVersion.h / .cpp       # 游戏版本检测（Game.exe / Unknown）
│   ├── Patch.h / .cpp             # 内存补丁工具箱（WriteJmp/WriteBytes/JnzToJmp...）
│   ├── Trampoline.h / .cpp        # 跳板式 inline hook 基础设施
│   ├── GameApi.h / .cpp           # 游戏函数地址与类型统一管理（gameapi::addr:: / Fn typedefs）
│   ├── Feature.h                  # Feature 抽象基类 + FeatureRegistry + REGISTER_FEATURE 宏
│   ├── FeatureManager.h / .cpp    # 遍历 registry → 查 INI Enabled → 调 OnInstall
│   ├── Paths.h                    # DLL 自身目录解析（GetModuleHandleExA 技巧）
│   └── fs_compat.h               # 文件系统兼容层（v141 <experimental/filesystem>）
├── Features/                      # ---- 功能模块层 ----
│   ├── SigCheckFeature.cpp        # [SigCheck] 签名校验禁用
│   └── StoreAllFishFeature.cpp    # [StoreAllFish] 商店扩展（3 个 inline hook + 跳板 + 中继）
└── InsaniquariumGameExtend.vcxproj # Win32-only / v141 / ConformanceMode=false
```

**关键设计**：
- Feature 的 `.cpp` 文件**直接 `#include` 进 `dllmain.cpp`**（不在 .vcxproj 中单独编译）。
  这样 `REGISTER_FEATURE` 宏的静态注册对象与 DllMain 在同一翻译单元，
  保证 DllMain 执行前 registry 已填满。
- 所有游戏函数地址（VA 常量）、函数指针 typedef（`Fn5409B0` 等）、
  `Va()` / `VaToRva()` 助手统一在 `GameApi.h` 声明，Feature 不得散落声明。
- DllMain **同步安装** hook（不另起工作线程）：
  ModLoader 在 `CREATE_SUSPENDED` 状态下注入，DllMain 返回后 `ResumeThread`
  才让游戏代码跑，因此 DllMain 里直接装 hook 能保证先于游戏任何代码执行。

## 二、前提

- 本机已装 **Visual Studio 2017（v141 工具集）** + Windows 10 SDK（v7.1A 兼容）。
- 必须有**未修改的原版 Game.exe**（sha256 开头 `312021e9…`）。
  ⚠️ 不要用 3.5MB 的「怪怪水族箱.exe」——那是被 HEX-CN 改过的本体，RVA 全漂移，本 mod 的 hook 地址会装错，必然崩溃。
- 已有 ModLoader（InsaniquariumModLoader.exe），负责把 DLL 注入到「挂起态」的 Game.exe。

## 三、编译（Win32 / Release，x86）

1. 打开 `G:/Projects/InsaniquariumGameExtend/InsaniquariumGameExtend.sln`。
2. 顶部工具栏：**解决方案配置 = Release**，**解决方案平台 = Win32（x86）**。
   —— 务必是 Win32 / x86，不能是 x64；Game.exe 是 32 位，混编会崩。
3. 若 VS 提示升级/重定目标 → 选「保持 v141」（VS2017）；不要升级到更高工具集（除非你确认能编过）。
4. 生成 → 生成 InsaniquariumGameExtend（或 `Ctrl+Shift+B`）。
5. 成功产物：`InsaniquariumGameExtend\bin\Release\InsaniquariumGameExtend.dll`。

   常见报错：
   - **C2760**：确认 .vcxproj 含 `<ConformanceMode>false</ConformanceMode>`（已为 v7.1A SDK 兼容添加；v7.1A 头与 `/permissive-` 冲突）。
   - **找不到 Windows.h / SDK 缺失**：在 VS 安装器里勾装「Windows 10 SDK (10.0.xxxxx)」。
   - **LNK2001 未解析符号**：检查是否误把 Feature `.cpp` 加进了 .vcxproj 的 `<ClCompile>`——Feature 文件应只被 `dllmain.cpp` 的 `#include` 引入，不参与独立编译。

## 四、部署

1. 把 `bin\Release\InsaniquariumGameExtend.dll` 复制到 **ModLoader.exe 同级目录**。
2. 同目录放 `InsaniquariumGameExtend.ini`：
   - **仓库里已有一份模板**：`InsaniquariumGameExtend\InsaniquariumGameExtend.ini`，直接拷过去即可。
   - **或者**：什么都不放也行——DLL 首次运行会通过 `EnsureDefaultIni()` 自动在自身目录
     生成一份带注释的默认配置（两个 Feature 均 `Enabled = 1`），日志会打
     `[Boot] Default config generated: ...`。
   - INI 内容示例：
     ```ini
     [SigCheck]
     ; 禁用 .sig 签名校验（让被修改的 partner.xml 等能正常加载）
     ; 1 = 禁用（默认，推荐）；0 = 恢复原版（仍做签名校验）
     Enabled = 1

     ; 禁用方式
     ; 1 = 分支补丁（改 sub_486DF0 的 jnz -> jmp，报错分支不可达）
     ; 2 = 函数替换（把 .sig 校验器整体换成永远返回成功）
     Method = 1

     [StoreAllFish]
     ; 商店扩展：把被隐藏的鱼/道具也放到商店（分到 7..14 槽，双行显示），
     ; 含 6 种鱼 + 星药剂 + 捕星者，同时保留"买 X 解锁 Y"的科技树进度。
     ; 1 = 启用（默认）；0 = 完全回退原版商店逻辑
     Enabled = 1
     ```
3. 确认原版 `Game.exe` 在游戏目录（ModLoader 会启动它）。

## 五、运行与验证

1. 用 ModLoader 启动游戏（它先以挂起态起 Game.exe → 注入 DLL → ResumeThread，DLL 在游戏代码跑之前就装好 hook）。
2. 进入商店（任意关），应看到：
   - **第 1 行**：原有 0..6 升级项（科技树不变）。
   - **第 2 行**：6 种鱼（guppy / breeder / carnivore / guppycruncher / beetlemuncher / ultravore）+ 星药剂 + 捕星者，双行布局。
3. 打开日志确认 Feature 已安装（DLL 同目录 `logs\InsaniquariumGameExtend.log`），应有：

   ```
   [Boot] === InsaniquariumGameExtend attached ===
   [Boot] INI loaded: ...
   [FeatureManager] Installing Feature 'SigCheck' ...
   [SigCheck] Game.exe base = ...
   [SigCheck] Method = 1
   [SigCheck] [Method1] target = jnz in sub_486DF0 ...
   [SigCheck] [OK] SigCheck disabled (Method1: jnz -> jmp). ...
   [FeatureManager] Feature 'SigCheck' installed OK.
   [FeatureManager] Installing Feature 'StoreAllFish' ...
   [StoreAllFish] Installed (sub_5409B0 + sub_541200 + sub_538090). Hidden 8 items will be placed in slots 7..14 with dual-row display, clickable for purchase.
   [FeatureManager] Feature 'StoreAllFish' installed OK.
   [FeatureManager] Installed 2/2 features ...
   [Boot] Extend framework initialized, 2 feature(s) active.
   ```

   - 若出现 `[StoreAllFish] sub_54xxB0 trampoline install failed.` → 目标地址算错，多半是 Game.exe 不是未修改原版或版本不符。
   - 若出现 `[FeatureManager] Feature 'XXX' disabled (Enabled=0), skip.` → INI 中该 Feature 被关闭。

## 六、已知风险与排查

- **2 行按钮可能与下方缸体/预览区垂直重叠**：代码里 `y = 3 + row*63`，第 2 行 y≈66。若挡住内容，调小 63（如 55）或把第 1 行上移。
  位置在 `Features/StoreAllFishFeature.cpp` 的 `Sub5409B0_Hook` 函数内。
- **未解锁鱼的购买逻辑**：本 mod 只强制「按钮可见」，不绕过科技树前置。若某鱼前置未满足，点了仍按原版行为（或无效）——这是「保留科技树」的设计预期。
- **实现机制（便于排查）**：对本关被隐藏的鱼，hook 把槽位字段**临时降为 0** 让原版安全建好按钮（new+虚表+AddWidget+SetBounds），再把字段与 `slot0` 缓存还原，最后把按钮重摆到第二行并存**自有缓存 `g_fishCache`**（按 slot 索引）。**绝不写原版 `*(this+257+slot)`**（slot≥7 会越界写堆 → 堆损坏崩溃）。
- **点击购买的前提是 3 个 hook 全装好**：`sub_5409B0`（建按钮）、`sub_541200`（分槽+触发创建）、`sub_538090`（购买闸门）。漏装 `sub_538090` = 第二行按钮可见但点了没反应。
- **若第 2 行按钮不出现/异常**：先看日志有无 `[StoreAllFish] Installed ...`；再确认用的是未修改原版 Game.exe（sha256 312021e9…）。

## 七、新增 Feature（扩展开发指南）

新增一个功能只需 3 步：

1. 在 `Features/` 下新建 `MyFeatureFeature.cpp`，继承 `Feature`，实现 `GetName()` / `GetTarget()` / `OnInstall()`，底部写 `REGISTER_FEATURE(MyFeature)`。
2. 在 `dllmain.cpp` 底部加一行 `#include "Features/MyFeatureFeature.cpp"`。
3. 在 `InsaniquariumGameExtend.ini` 加一个 `[MyFeature]` 段，写 `Enabled = 1`。

游戏函数地址统一在 `Core/GameApi.h` 的 `addr::` 命名空间补常量；函数指针类型在下方 `Fn` 区补 `typedef`。不要在 Feature 文件里散落声明。

## 八、关闭 / 回退

- 不想用某个 Feature：INI 对应段设 `Enabled = 0`（hook 不装，行为完全原版）。
- 全部关闭：两个段都设 `Enabled = 0`，DLL 变空壳（仅初始化日志和配置，不改任何游戏行为）。
- 任何异常：删 DLL 即恢复。
