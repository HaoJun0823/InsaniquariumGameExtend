# 构建与测试指南：商店「提供所有鱼」扩展（InsaniquariumGameExtend）

本指南对应 dllmain.cpp 中「提供所有鱼」功能（hook sub_5409B0 + sub_541200），
实现：保留升级项科技树 + 把本关被隐藏的 6 种鱼强制显示到双行第 2 行。

---

## 一、前提
- 本机已装 **Visual Studio 2017（v141 工具集）** + Windows 10 SDK（v7.1A 兼容）。
- 必须有**未修改的原版 Game.exe**（sha256 开头 `312021e9…`）。
  ⚠️ 不要用 3.5MB 的「怪怪水族箱.exe」——那是被 HEX-CN 改过的本体，RVA 全漂移，本 mod 的 hook 地址会装错，必然崩溃。
- 已有 ModLoader（InsaniquariumModLoader.exe），负责把 DLL 注入到「挂起态」的 Game.exe。

## 二、编译（Win32 / Release，x86）
1. 打开 `G:/Projects/InsaniquariumGameExtend/InsaniquariumGameExtend.sln`。
2. 顶部工具栏：**解决方案配置 = Release**，**解决方案平台 = Win32（x86）**。
   —— 务必是 Win32 / x86，不能是 x64；Game.exe 是 32 位，混编会崩。
3. 若 VS 提示升级/重定目标 → 选「保持 v141」（VS2017）；不要升级到更高工具集（除非你确认能编过）。
4. 生成 → 生成 InsaniquariumGameExtend（或 `Ctrl+Shift+B`）。
5. 成功产物：`InsaniquariumGameExtend\bin\Release\InsaniquariumGameExtend.dll`。

   常见报错：
   - **C2760**：确认 .vcxproj 含 `<ConformanceMode>false</ConformanceMode>`（已为 v7.1A SDK 兼容添加；v7.1A 头与 `/permissive-` 冲突）。
   - **找不到 Windows.h / SDK 缺失**：在 VS 安装器里勾装「Windows 10 SDK (10.0.xxxxx)」。

## 三、部署
1. 把 `bin\Release\InsaniquariumGameExtend.dll` 复制到 **ModLoader.exe 同级目录**。
2. 同目录放 `InsaniquariumGameExtend.ini`：
   - **仓库里已有一份带注释的模板**：`InsaniquariumGameExtend\InsaniquariumGameExtend.ini`，
     直接拷过去即可（含 `StoreAllFish` / `DisableSigCheck` / `SigCheckMethod` 全部开关）。
   - **或者**：什么都不放也行——DLL 首次运行会自动在自身目录生成这份带注释的 INI
     （日志会打 `[配置] 已自动生成默认配置文件：...`）。之后你就能在文件里看到并改 `StoreAllFish`。
   - INI 内容示例：
     ```ini
     [Mod]
     StoreAllFish=1        ; 1=启用商店扩展（默认）；0=关闭（完全原版行为）
     DisableSigCheck=1     ; 跳过 partner.xml 的 .sig 校验（本项目需要）
     SigCheckMethod=1      ; 禁用方式：1=分支补丁，2=函数替换
     ```
3. 确认原版 `Game.exe` 在游戏目录（ModLoader 会启动它）。

## 四、运行与验证
1. 用 ModLoader 启动游戏（它先以挂起态起 Game.exe → 注入 DLL → ResumeThread，DLL 在游戏代码跑之前就装好 hook）。
2. 进入商店（任意关），应看到：
   - **第 1 行**：原有 0..6 升级项（科技树不变）。
   - **第 2 行**：6 种鱼（guppy / breeder / carnivore / guppycruncher / beetlemuncher / ultravore），双行布局。
3. 打开日志确认 hook 已安装（DLL 同目录）：
   看 `logs\InsaniquariumGameExtend.log`，应有：
   - `[商店扩展] 已安装（sub_5409B0 + sub_541200）。被隐藏的鱼将分到 7..12 槽并双行显示。`
   - 若出现 `[商店扩展][错误] sub_54xxB0 跳板安装失败。` → 目标地址算错，多半是 Game.exe 不是未修改原版或版本不符。

## 五、已知风险与排查
- **2 行按钮可能与下方缸体/预览区垂直重叠**：代码里 `y = 3 + row*63`，第 2 行 y≈66。若挡住内容，调小 63（如 55）或把第 1 行上移。
- **未解锁鱼的购买逻辑**：本 mod 只强制「按钮可见」，不绕过科技树前置。若某鱼前置未满足，点了仍按原版行为（或无效）——这是「保留科技树」的设计预期。
- **实现机制（便于排查）**：对本关被隐藏的鱼，hook 把槽位字段**临时降为 0** 让原版安全建好按钮（new+虚表+AddWidget+SetBounds），再把字段与 `slot0` 缓存还原，最后把按钮重摆到第二行并存**自有缓存 g_fishCache**（按 slot 索引）。**绝不写原版 `*(this+257+slot)`**（slot≥7 会越界写堆 → 堆损坏崩溃）。因此已不再依赖 `sub_5373C0` 的内部约定。
- **若第 2 行按钮不出现/异常**：先看日志 `logs\InsaniquariumGameExtend.log` 有无 `[商店扩展] 已安装`；再确认用的是未修改原版 Game.exe（sha256 312021e9…）。

## 六、关闭 / 回退
- 不想用扩展：INI 设 `StoreAllFish=0`（hook 不装，行为完全原版）。
- 任何异常：删 DLL 或设 `StoreAllFish=0` 即恢复。
